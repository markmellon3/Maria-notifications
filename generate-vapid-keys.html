VAPID Key Generator

Generate Web Push VAPID keys directly in your browser. These keys are used by the SMMARIA notification backend to send push notifications.

VAPID_PUBLIC_KEY
—
VAPID_PRIVATE_KEY
—
Where to put these keys:

1. VAPID_PUBLIC_KEY → paste into your .env file
2. VAPID_PRIVATE_KEY → paste into your .env file
3. Both go into Railway → Settings → Variables

Security: The private key must NEVER be shared publicly or put in frontend code. Only the public key is safe to expose to browsers.
